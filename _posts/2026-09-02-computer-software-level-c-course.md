## 電腦軟體應用丙級術科在考什麼？

電腦軟體應用丙級（職類編號 **11800**）的術科測驗，考的不是天花亂墜的高深技巧，而是**職場天天用得到的文書處理能力**。

術科試題一共分成 **15 個題組**（試題編號 118-920301 ~ 118-920345），考試時會從中抽出題目。而**每個題組都包含 4 個題型**，依序是：

1. **檔案管理**：在視窗作業系統中建立資料夾、搬移／複製／重新命名檔案、排序與檢視設定
2. **目錄製作**：用 Word 的自動目錄功能產出章節目錄與頁碼，不用再手動慢慢打
3. **合併列印**：把名單資料套用到文件／標籤大量產出，文書工作者的必學功能
4. **文書處理**：匯入文字、設定邊界與頁首頁尾、取代與全形半形、字型與段落格式、圖片排版、表格製作與進階格式

其中**文書處理**佔分最重也最花時間，是整個術科最需要練習的部分。

## 為什麼即使不考證照也值得學？

這些題型其實就是**職場最常用的文書技能**：

- 文字匯入與分段整理
- 邊界、頁首頁尾設定
- 取代、全形半形轉換
- 字型、段落格式（縮排、對齊、框線、網底）
- 圖片排版（文繞圖、尺寸、陰影）
- 表格製作與進階格式（合併儲存格、直書、斜線、欄寬）

這些能力，無論是**打報告、做履歷、寫企劃書、做產品說明書**都用得到，可以說是一生受用的基本功。

## 自己練習怎麼知道對不對？── 我做的自動評分系統

練術科最痛苦的就是**不知道自己的作答到底對不對**。所以我打造了一套免費的線上評分工具：

👉 **11800-word-scoring（電腦軟體應用丙級·文書處理評分系統）**：<https://github.com/vanix/11800-word-scoring>

### 功能特色

- **分階段評分**：每個題組拆成多個階段，各自獨立定義檢查項
- **檢查內容超完整**：版面、邊界、頁首尾、字型、段落、取代、兩欄、圖片、表格……通通自動檢查
- **扣分制**：滿分 100、60 分及格，給了就知道自己卡在哪
- **逐字比對**：用「編輯距離」演算法（Levenshtein）比對文字，「少打一個字扣 3 分」也能精準抓到
- **上傳記錄自動儲存**：練習記錄寫入 `uploads/submissions.csv`，方便追蹤進步

### 怎麼用？

只要三行程式就搞定：

```bash
pip install flask
python app.py
```

然後打開瀏覽器進入 <http://localhost:5000>，把作答的 `.docx` 丟上去，就會看到分數與每個檢查項的判定結果。

> 📌 macOS 若發現 5000 埠被 ControlCenter 佔用，改用其他埠：
> ```bash
> python3 -c "from app import app; app.run(debug=False, host='0.0.0.0', port=5001)"
> ```

規格上已預設綁定 `0.0.0.0`，若要區域網路連線，其他電腦用 `http://你的IP:5000` 也能連；連不到時記得在 Windows 防火牆開放 5000 埠。

整個系統只用 Python **標準函式庫**＋一個 Flask，純粹、輕量、相容 Python 3.14，註解完整，想看懂或擴充都很容易。
