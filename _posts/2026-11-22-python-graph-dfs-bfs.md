## 快速答案：Python 圖論入門要先學什麼？

> **快速答案：** 學圖論入門，先搞懂「節點與邊」怎麼表示題目，再用**鄰接表**把圖存起來，最後掌握兩個走訪模板：**DFS（深度優先搜尋）**適合判斷能不能到、走訪整個連通區塊；**BFS（廣度優先搜尋）**適合無權圖的最短步數。這兩個模板學會後，就能開始解 ZeroJudge 的基礎圖論題。

## 1. 圖是什麼？

**圖（Graph）是用來表示「東西之間有沒有關係」的資料結構。** 很多題目表面上是城市、迷宮、課程先修或朋友關係，其實都可以先轉成圖再處理。

### 1.1 基本元素：節點與邊

- **節點（Vertex / Node）**：圖中的一個點，代表一個物件，例如城市、人、格子、狀態。
- **邊（Edge）**：連接兩個節點的線，代表它們之間有關係，例如道路、好友、可以走過去。

```text
無向圖範例：

        (A) -------- (B)
         | \          |
         |   \        |
         |     \      |
        (C) -------- (D)

節點：A、B、C、D
邊：A-B、A-C、A-D、B-D、C-D
```

這張圖代表 A 和 B 有連線、A 和 C 有連線……沒有畫出來的就代表沒有直接連線，例如 B 和 C 之間沒有邊。

### 1.2 相鄰與度數

- **相鄰（Adjacent）**：兩個節點之間有邊直接相連，就稱為相鄰。
- **度數（Degree）**：一個節點連出去的邊數。

```text
        (A) -------- (B)
         | \          |
         |   \        |
         |     \      |
        (C) -------- (D)

A 的相鄰節點：B、C、D  → 度數 = 3
B 的相鄰節點：A、D     → 度數 = 2
C 的相鄰節點：A、D     → 度數 = 2
D 的相鄰節點：A、B、C  → 度數 = 3
```

### 1.3 無向圖 vs 有向圖

- **無向圖（Undirected Graph）**：邊沒有方向，A-B 代表可以從 A 走到 B，也可以從 B 走到 A。
- **有向圖（Directed Graph）**：邊有方向，只能順著箭頭走。

```text
無向圖：像雙向道路

    (A) --- (B)
     |       |
    (C) --- (D)

A --- B 代表：A → B 可以，B → A 也可以


有向圖：像單行道

    (A) --> (B)
     |       |
     v       v
    (C) --> (D)

A → B 可以，但 B → A 不行
```

### 1.4 無權圖 vs 帶權圖

- **無權圖（Unweighted Graph）**：邊只表示「有連接」，不帶數值。
- **帶權圖（Weighted Graph）**：邊上有權重（weight），常代表距離、時間、成本。

```text
無權圖：只關心有沒有路

    (A) --- (B)
     |       |
    (C) --- (D)


帶權圖：還關心這條路的成本

    (A) --5-- (B)
     |         |
     2         1
     |         |
    (C) --3-- (D)

A 到 B 的成本是 5
A → C → D → B 的成本是 2 + 3 + 1 = 6
```

**入門圖論題通常先從無權圖開始。** 無權圖的最短步數可以用 BFS 解決；帶權圖的最短路徑則需要 Dijkstra 等演算法，這篇先不展開。

### 1.5 路徑、環、連通分量

- **路徑（Path）**：從某個節點出發，沿著邊走到另一個節點的路線。
- **環（Cycle）**：從某個節點出發，走一圈又回到自己。
- **連通圖（Connected Graph）**：無向圖中，任意兩個節點都至少有一條路可以互相到達。
- **連通分量（Connected Component）**：不連通的圖會分成幾個獨立區塊，每個區塊內部互通，區塊之間走不到。

```text
有環圖：可以繞一圈回到起點

    (A) --- (B)
     |       |
    (C) --- (D)

路徑例子：A → B → D
環例子：A → B → D → C → A


不連通圖：分成多個連通分量

    連通分量 1        連通分量 2
    (A) --- (B)       (E) --- (F)
     |
    (C)               (D)

A、B、C 互通，是一個分量
E、F 互通，是另一個分量
D 自己一個點，也算一個連通分量
```

### 1.6 樹與圖的關係

**樹（Tree）是連通且沒有環的無向圖。** 這也是為什麼題庫中的樹類題目，常常可以用圖的 DFS/BFS 思維來解。

```text
樹（Tree）：

        (1)
       /   \
     (2)   (3)
     / \
   (4) (5)

特徵：
- 5 個節點、4 條邊
- 任意兩點之間只有唯一一條路徑
- 沒有環
```

### 1.7 怎麼把題目看成圖？

看到題目時，先問自己三個問題：

1. **節點是什麼？**
2. **邊是什麼？**
3. **有方向嗎？有權重嗎？**

| 題目情境 | 節點 | 邊 | 圖的類型 |
| --- | --- | --- | --- |
| 城市之間有道路，問能不能到達 | 城市 | 道路 | 無向、無權 |
| 迷宮從起點走到終點最少幾步 | 格子 | 相鄰可走的格子 | 無向、無權 |
| 課程有先修關係 | 課程 | A 是 B 的先修 | 有向、無權 |
| 地圖上每條路有距離，求最短距離 | 地點 | 道路與距離 | 有向或無向、帶權 |

## 2. Python 怎麼存圖？

圖的存法有很多種，入門最常用的是**鄰接表（Adjacency List）**。它的概念很簡單：幫每個節點準備一個串列，記錄它可以直接走到哪些鄰居。

### 鄰接表：入門首選

```python
# 5 個節點，編號 1~5
n = 5
adj = [[] for _ in range(n + 1)]  # adj[0] 不用，方便用 1-based 編號

# 加入無向邊
edges = [(1, 2), (1, 3), (2, 4), (2, 5)]
for u, v in edges:
    adj[u].append(v)
    adj[v].append(u)

print(adj[1])  # [2, 3]
print(adj[2])  # [1, 4, 5]
```

範例輸出：

```text
[2, 3]
[1, 4, 5]
```

這個輸出代表：節點 1 的鄰居是 2、3；節點 2 的鄰居是 1、4、5。**鄰接表適合稀疏圖，也是 ZeroJudge 圖論題最常用的寫法。**

### 鄰接矩陣：節點少時才考慮

鄰接矩陣用二維串列表示，`matrix[u][v] = 1` 代表有邊。

```python
n = 4
matrix = [[0] * (n + 1) for _ in range(n + 1)]
matrix[1][2] = 1
matrix[2][1] = 1  # 無向圖要兩邊都設
```

它的優點是查「兩點有沒有邊」很快，但如果節點很多，記憶體會爆炸。一般入門題用鄰接表就夠了。

| 存法 | 適合情境 | 優點 | 注意事項 |
| --- | --- | --- | --- |
| 鄰接表 | 大多數圖論題、稀疏圖 | 省空間、好走訪鄰居 | 查兩點是否直接相連較慢 |
| 鄰接矩陣 | 節點很少、要常查某兩點有無邊 | 查邊 O(1) | 節點多時記憶體大 |
| 邊列表 | 只需要掃過所有邊 | 寫法簡單 | 不方便直接找鄰居 |

## 3. 建圖模板：從輸入到鄰接表

ZeroJudge 圖論題常見輸入是：第一行給節點數 `n` 和邊數 `m`，接下來 `m` 行每行給一條邊 `u v`。

範例輸入：

```text
5 4
1 2
1 3
2 4
2 5
```

```python
import sys
sys.setrecursionlimit(10**7)
input = sys.stdin.readline

n, m = map(int, input().split())
adj = [[] for _ in range(n + 1)]

for _ in range(m):
    u, v = map(int, input().split())
    adj[u].append(v)
    adj[v].append(u)  # 無向圖才要加這行

for i in range(1, n + 1):
    print(i, adj[i])
```

範例輸出：

```text
1 [2, 3]
2 [1, 4, 5]
3 [1]
4 [2]
5 [2]
```

這組輸入代表 5 個節點、4 條無向邊。建完圖後，從輸出就能檢查每個節點的鄰居是否正確。

### 建圖時要注意的細節

- **無向圖要加兩次**：`u -> v` 和 `v -> u` 都要加入。
- **有向圖只加一次**：題目說「A 到 B」或有箭頭方向，就只加 `adj[u].append(v)`。
- **1-based 編號**：題目常從 1 開始編號，直接開 `n + 1` 個位置最省事。
- **visited 陣列大小也要一致**：用 `visited = [False] * (n + 1)`。

## 4. DFS 深度優先搜尋怎麼寫？

**DFS（Depth-First Search，深度優先搜尋）是一條路先走到底，走不通再回頭的搜尋方法。** 它很適合處理「能不能到達」、「有幾個連通分量」、「從某點能走到哪些點」這類問題。

### DFS 走訪順序示意

```text
圖：
        (1)
       /   \
     (2)   (3)
     / \
   (4) (5)

從 1 開始 DFS（先走左邊）的一種走訪順序：
1 → 2 → 4 → 回到 2 → 5 → 回到 2 → 回到 1 → 3

重點：先往深處走，走到底才回頭。
```

### DFS 遞迴模板（Python）

範例輸入：

```text
5 4
1 2
1 3
2 4
2 5
```

這組輸入會建立下面這棵樹（無向圖）：

```text
        (1)
       /   \
     (2)   (3)
     / \
   (4) (5)
for _ in range(m):
    u, v = map(int, input().split())
    adj[u].append(v)
    adj[v].append(u)

visited = [False] * (n + 1)
order = []

def dfs(cur):
    visited[cur] = True
    order.append(cur)
    for nxt in adj[cur]:
        if not visited[nxt]:
            dfs(nxt)

dfs(1)
print('order =', order)
print('visited =', visited[1:])
```

範例輸出：

```text
order = [1, 2, 4, 5, 3]
visited = [True, True, True, True, True]
```

這個輸出表示從節點 1 出發，可以走到所有節點；`order` 是其中一種 DFS 走訪順序。若鄰居加入順序不同，DFS 的 `order` 也可能不同，但「能不能走到」的結果不變。

### DFS 模板重點

- `visited[cur] = True`：進入節點時就標記，避免重複走。
- `for nxt in adj[cur]`：把目前節點的鄰居都檢查一次。
- `sys.setrecursionlimit(10**7)`：Python 預設遞迴深度較小，深圖可能發生 `RecursionError`。

> **什麼時候想到 DFS？** 題目問「能不能走到」、「有幾個區塊」、「所有可達點」，通常先想 DFS。

## 5. BFS 廣度優先搜尋怎麼寫？

**BFS（Breadth-First Search，廣度優先搜尋）是一層一層往外擴散的搜尋方法。** 在無權圖中，BFS 第一次到達某個節點時，走過的邊數就是最短步數。

### BFS 走訪順序示意

```text
圖：
        (1)
       /   \
     (2)   (3)
     / \
   (4) (5)

從 1 開始 BFS 的走訪順序：
第 0 層：1
第 1 層：2, 3
第 2 層：4, 5

走訪順序：1 → 2 → 3 → 4 → 5
重點：先把同一層的鄰居看完，再往下一層。
```

### BFS 模板（不使用 deque）

題目要求不使用額外模組時，可以用 `list` 當佇列，搭配一個 `head` 索引表示目前取到哪裡，避免用 `pop(0)` 造成效率變差。

範例輸入：

```text
5 4
1 2
1 3
2 4
2 5
```

這組輸入對應的圖如下，BFS 會從 1 開始一層一層往外走：

```text
        (1)        ← 第 0 層
       /   \
     (2)   (3)     ← 第 1 層
     / \
   (4) (5)         ← 第 2 層
while head < len(queue):
    cur = queue[head]
    head += 1
    for nxt in adj[cur]:
        if not visited[nxt]:
            visited[nxt] = True  # 入隊時標記，不是出隊才標記
            queue.append(nxt)

print(queue)  # BFS 走訪順序
```

範例輸出：

```text
[1, 2, 3, 4, 5]
```

這個輸出代表從節點 1 開始，BFS 先走完第 1 層的 2、3，再走第 2 層的 4、5。

### BFS 模板重點

- **入隊時標記 visited**：如果等到出隊才標記，同一個節點可能被多次放進佇列。
- **`head` 代表佇列前端**：用 `head += 1` 取代 `pop(0)`。
- **無權最短路徑**：可以再開一個 `dist` 陣列，記錄從起點到每個點的步數。

### BFS 求最短步數範例

範例輸入：

```text
5 4
1 2
1 3
2 4
2 5
1 5
```

前兩個數字是 `n m`，接著 4 條邊，最後一行 `1 5` 代表要查從 1 到 5 的最少步數。圖的樣子如下：

```text
        (1)
       /   \
     (2)   (3)
     / \
   (4) (5)

從 1 到 5 的最短路徑：1 → 2 → 5（共 2 步）
```

```

範例輸出：

```text
2
```

從 1 到 5 的最短路徑是 `1 -> 2 -> 5`，共 2 步；因此輸出 `2`。如果目標走不到，`dist[target]` 會維持 `-1`。

> **什麼時候想到 BFS？** 題目問「最少幾步」、「最短距離」，而且每條邊成本一樣（無權圖），優先想 BFS。

## 6. DFS 和 BFS 怎麼選？

| 比較項目 | DFS | BFS |
| --- | --- | --- |
| 走訪方式 | 一條路走到底再回頭 | 一層一層往外擴散 |
| 常用資料結構 | 遞迴 / Stack | Queue |
| 適合問題 | 可達性、連通分量、路徑存在 | 無權圖最短步數、最少步數 |
| Python 注意 | 深圖要設 `sys.setrecursionlimit` | 用 `list + head` 可不需 deque |
| 第一次到達終點 | 不保證最短 | 無權圖中保證最短步數 |

**一句話判斷：問「有沒有路」先想 DFS，問「最少幾步」先想 BFS。**

## 8. 常見錯誤

1. **無向圖只加單邊**：忘記 `adj[v].append(u)`，導致明明有路卻走不到。
2. **BFS 在出隊才標記 visited**：同一節點會重複入隊，可能造成 TLE 或答案錯誤。
3. **沒設遞迴上限**：Python DFS 遇到深圖可能 `RecursionError`，記得 `sys.setrecursionlimit(10**7)`。
4. **1-based 編號開錯大小**：題目從 1 編號，陣列卻只開 `n`，會造成索引錯誤。
5. **圖不連通只跑一次 DFS/BFS**：若題目要找所有連通分量，要對每個未走訪節點都啟動一次搜尋。
6. **用 BFS 處理帶權圖最短路**：BFS 只適合無權圖或每條邊權重相同的情況。

## 常見問題 FAQ

### Q1：Python 寫 BFS 一定要用 deque 嗎？

不一定。`collections.deque` 很方便，但如果不想用額外模組，可以用 `list` 搭配 `head` 索引：`cur = queue[head]; head += 1`。這樣可以避免 `pop(0)` 每次搬移元素的成本。

### Q2：DFS 和 BFS 哪個比較重要？

兩個都重要。**DFS** 常用在可達性、連通分量、遞迴走訪；**BFS** 常用在無權圖最短步數。APCS 和 ZeroJudge 入門圖論題兩種都會遇到，建議兩個模板都背熟。

### Q3：什麼時候要用鄰接矩陣，不用鄰接表？

節點數很小（例如 `n <= 500`）且題目常需要判斷「某兩點是否直接相連」時，鄰接矩陣會比較方便。一般圖論題節點數較大或邊較稀疏時，用鄰接表更安全。

### Q4：題目沒有明說是圖，我怎麼判斷？

先找「物件」與「關係」。如果題目有城市與道路、格子可移動方向、朋友關係、任務先後順序、網路連線，就很可能是圖。把物件當節點、關係當邊，問題通常會清楚很多。

### Q5：樹的題目可以用圖的方法做嗎？

可以。樹是連通且無環的無向圖，所以 DFS/BFS 常常能直接用。只是有些樹題目有更適合的資料結構，例如二元搜尋樹的插入與走訪，要依題目需求選擇。

## 總結

圖論入門不用一次學太多，先把這條路線走穩就夠了：

1. **看懂圖**：節點、邊、無向/有向、無權/帶權、連通分量。
2. **會存圖**：用鄰接表把輸入轉成 `adj`。
3. **會走圖**：DFS 處理可達性，BFS 處理無權最短步數。
4. **去刷題**：從 [APCS 基本題庫](https://vanix.github.io/apcs/problem-bank/) 的圖論題組開始練習。

把這四步練熟，之後再進入帶權最短路徑、拓撲排序、Union-Find 等主題，會順很多。
