## 特殊位置這題在考什麼？

題目會給你一個 n × m 的二維矩陣，每一格的數值都是 0 到 9 的整數。對矩陣裡的每一個位置 (i, j)，我們把該格的數字當作 x：

> 如果「離 (i, j) 曼哈頓距離在 x 以內的所有格子」的數值總和，除以 10 的餘數剛好等於 x，那 (i, j) 就是一個**特殊位置**。

你要做的事情很單純：**找出矩陣中所有的特殊位置，先輸出數量，再依座標由小到大輸出每一組座標**。

這題分成兩個子問題：

| 子問題 | 配分 | 範圍限制 |
| --- | --- | --- |
| 子問題一 | 60% | n = 1 |
| 子問題二 | 40% | n, m ≤ 50 |

即使是最暴力的四層迴圈做法，在 n、m ≤ 50 的資料量下也跑得完，所以這題不需要什麼高階技巧，重點是**觀念正確、邊界處理正確**。

> **先備能力**：建議先學會**二維陣列的存取**與**巢狀迴圈**再來挑戰。

![距離範圍超過矩陣邊界的示意](/assets/images/blog/apcs-k732-special/apcs-k732-bounds-outside.png){: .normal}
_距離範圍超過矩陣邊界時，界外的格子（灰色）不能算進來，只累加仍在矩陣內的格子。_

## 什麼是曼哈頓距離？

曼哈頓距離（Manhattan distance）指的是「只能上下左右移動」時，從一格走到另一格最少需要幾步。對兩個位置 (i, j) 和 (r, c) 來說，公式就是：

```text
曼哈頓距離 = |i - r| + |j - c|
```

因為在格子地圖上你不能斜著走，所以要把「列的差距」和「欄的差距」分開取絕對值再相加。舉例來說：

- (0, 0) 和 (0, 5)：距離 = |0-0| + |0-5| = 5
- (0, 0) 和 (2, 3)：距離 = |0-2| + |0-3| = 5
- (1, 1) 和它自己：距離 = 0

題目說的「距離在 x 以內」，就是**距離 ≤ x**。所以對某個值為 0 的格子來說，x = 0，只有它自己（距離 0）符合，這種格子幾乎都會是特殊位置——這是這題很容易忽略的小陷阱。

## 為什麼「超過邊界」的格子不能算？

看上面那張圖：假設某個格子 x 比較大，它畫出來的距離範圍會超出矩陣的上下左右。**超出矩陣的格子並不存在**，所以不能算進總和，也不能把它當成 0 硬加進去。

實作時只要在內層迴圈多寫一句邊界檢查就好：

```python
if r < 0 or r >= n or c < 0 or c >= m:
    continue
```

只有在矩陣內的格子才繼續做距離判斷與累加。

## 特殊位置怎麼判斷？

判斷流程分成兩步：

1. 算出距離範圍內所有格子的數值總和 `total`
2. 檢查 `total % 10` 是否等於 `x`（也就是該格的數值）

![以影片示範的矩陣為例，A[2][3] 是特殊位置](/assets/images/blog/apcs-k732-special/apcs-k732-special-position.png){: .normal}
_以影片示範的矩陣為例，某個位置經過累加與除以 10 取餘數後，剛好等於該格數字，就是特殊位置。_

一個很常見的誤會是「要不要包含自己這一格？」**要**。距離 0 的格子就是它自己，而 0 ≤ x 永遠成立，所以自己一定在範圍內。用官方的第二筆範例就能驗證：2 × 3 矩陣總和是 25，25 % 10 = 5，剛好等於 (0, 0) 這一格的數字 5；如果漏掉自己，總和會變成 20，20 % 10 = 0 就對不上了。

## 輸入格式怎麼看？

第一行給你兩個整數 n 和 m，代表矩陣有幾列、幾欄。接下來有 n 行，每行 m 個整數，就是矩陣內容：

```text
2 3
5 2 3
4 5 6
```

![影片中第二個範例的輸入資料](/assets/images/blog/apcs-k732-special/apcs-k732-example2-input.png){: .normal}
_輸入資料就是先讀「列數 欄數」，再把整個矩陣讀進來。_

讀取時可以直接用串列推導式把它存成二維陣列：

```python
n, m = map(int, input().split())
a = [list(map(int, input().split())) for _ in range(n)]
```

## 解題流程總覽（四層迴圈）

整題的邏輯可以拆成兩組迴圈，總共四層：

![解題流程總覽：外層兩層掃描每個格子，內層兩層掃描距離範圍](/assets/images/blog/apcs-k732-special/apcs-k732-overview.png){: .normal}
_外層兩層迴圈依序走過每一個格子，內層兩層迴圈針對「目前格子的距離範圍」逐一檢查。_

- **外層兩層迴圈**：從左上角開始，一格一格掃描整個矩陣，走到每個位置 (i, j)。
- **內層兩層迴圈**：對目前這個 (i, j)，把範圍鎖定在列 `i-x` 到 `i+x`、欄 `j-x` 到 `j+x` 的方框內，逐一檢查每個候選格子。
- **判斷**：候選格子必須 (1) 在矩陣內，而且 (2) 與 (i, j) 的曼哈頓距離 ≤ x，符合才把它的數值加到 `total`。
- **收尾**：算完 `total` 後檢查 `total % 10 == x`，成立就把座標存進答案串列。

因為我們是**從上到下、從左到右**掃描，答案串列自然就會是題目要求的「座標由小到大（字典序）」順序，最後照順序印出即可，不用另外排序。

## 完整程式碼

![完整程式碼與流程示意圖](/assets/images/blog/apcs-k732-special/apcs-k732-full-code.png){: .normal}
_完整程式碼：讀入矩陣、四層迴圈檢查、最後依序輸出數量與座標。_

```python
n, m = map(int, input().split())
a = [list(map(int, input().split())) for _ in range(n)]

ans = []
for i in range(n):
    for j in range(m):
        x = a[i][j]
        total = 0
        for r in range(i - x, i + x + 1):
            for c in range(j - x, j + x + 1):
                if r < 0 or r >= n or c < 0 or c >= m:
                    continue
                if abs(r - i) + abs(c - j) <= x:
                    total += a[r][c]
        if total % 10 == x:
            ans.append((i, j))

print(len(ans))
for i, j in ans:
    print(i, j)
```

幾個實作小提醒：

- 內層迴圈範圍用 `range(i - x, i + x + 1)`，記得 `+1` 才會包含到 `i + x`。
- 邊界檢查放在距離判斷前面，先 `continue` 掉界外的格子，可讀性最好。
- 輸出座標是 **0-indexed**（第一列第一欄是 `0 0`），不要印成 1-indexed。

## 範例走讀

### 範例 1：1 × 8 的一列矩陣

```text
輸入
1 8
1 2 3 4 5 6 7 8

輸出
1
0 5
```

只有 (0, 5) 這一格是特殊位置：它的數字是 6，距離 6 以內包含整列 8 個數字，總和 36，36 % 10 = 6，剛好等於自己。其他格子的餘數都對不上。

### 範例 2：2 × 3 的小矩陣

```text
輸入
2 3
5 2 3
4 5 6

輸出
2
0 0
1 1
```

矩陣總和是 5 + 2 + 3 + 4 + 5 + 6 = 25。

- (0, 0) 數字是 5，距離 5 以內剛好涵蓋全部 6 格，總和 25，25 % 10 = 5 ✅
- (1, 1) 數字是 5，同樣涵蓋全部 6 格，總和 25，25 % 10 = 5 ✅

兩組座標正好由小到大排列。

## 常見錯誤與除錯

- **漏算自己那一格**：距離 0 也是「在 x 以內」，自己一定要算進去。
- **把界外的格子當 0 加進去**：界外的格子不存在，忽略它，不是當 0。
- **距離判斷用「< x」**：題目是「x 以內」，要用「≤ x」。特別注意 x = 0 的格子只會包含自己。
- **輸出座標顛倒**：題目的座標是「列 欄」，先列（i）再欄（j），而且要從 0 開始。
- **答案順序**：只要乖乖用巢狀迴圈由上到下、由左到右掃描，就會天然照字典序排好。

## 常見問題（FAQ）

### Q1：特殊位置這題一定要用四層迴圈嗎？
以 n, m ≤ 50 的資料量來說，四層迴圈（O(n²m²)）已經足夠，因為最大也只不過 50 × 50 × 19 × 19 左右的運算量。重點是觀念清楚，不必刻意追求更快的寫法。

### Q2：曼哈頓距離跟歐幾里得距離差在哪？
歐幾里得距離是直線距離（會用到平方、開根號）；曼哈頓距離只能上下左右移動，公式是 `|i - r| + |j - c|`。這題用的是曼哈頓距離。

### Q3：座標要從 0 還是 1 開始算？
從 **0** 開始。第一列第一欄輸出成 `0 0`，範例輸出可以直接對照。

### Q4：如果某格數字是 0 會怎樣？
x = 0，距離 0 以內只有它自己，總和就是 0，0 % 10 = 0 等於 x，所以這種格子幾乎都是特殊位置。這是新手最常漏掉的邊界情況。

### Q5：為什麼輸出不需要另外排序？
因為掃描順序是「由上到下、由左到右」，正好等於題目要求的字典序，存進答案的順序就是印出的順序。

## 小結

「特殊位置」是 APCS 中級用來練**二維陣列**與**距離判斷**的經典題。把曼哈頓距離、邊界處理、以及「自己也要算」這三件事搞定，四層迴圈寫法就能穩定通過。建議你先自己照著邏輯寫一遍，卡關時再看程式碼，會學得最紮實。

如果覺得二維陣列還不熟，可以先從矩陣翻轉、旋轉這類基本題開始練手感，再回來挑戰特殊位置。
