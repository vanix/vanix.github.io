## 遊戲選角這題在考什麼？

**遊戲選角要你先算出每個角色的綜合能力（攻擊力² + 防禦力²），找出綜合能力第二高的角色，然後輸出那個角色原本的攻擊力與防禦力。** 注意是輸出「攻擊力與防禦力」，不是輸出綜合能力的數值。

這是 APCS 程式實作初級 2024 年 1 月範例的第一題（ZeroJudge 編號 [m931](https://zerojudge.tw/ShowProblem?problemid=m931){:target="_blank"}），題意相對單純，但藏了一個小陷阱，也就是「找到第二名之後，還要能找回它本來的資料」。

_題目的核心：用攻擊力與防禦力的平方和當作角色的綜合能力。_

## 輸入格式怎麼看？

輸入規則如下：

| 欄位 | 內容 | 說明 |
| --- | --- | --- |
| 第 1 行 | 一個整數 `n` | 有幾個角色（同時也是迴圈要跑幾次），3 ≤ n ≤ 20 |
| 之後 `n` 行 | 每行 2 個正整數 | 依序是這名角色的「攻擊力」與「防禦力」，介於 1 到 100，中間以空白間隔 |

題目保證**所有角色的綜合能力值都相異**，所以不會有兩名角色同分、需要比第二名的情況。

## 綜合能力怎麼算？

**綜合能力 = 攻擊力² + 防禦力²。** 題目用「平方和」來評估角色的強度，數值越大的角色越強。

以範例的三名角色為例：

| 角色 | 攻擊力 | 防禦力 | 綜合能力（平方和） |
| --- | --- | --- | --- |
| 一號 | 3 | 2 | 3² + 2² = 9 + 4 = **13** |
| 二號 | 5 | 2 | 5² + 2² = 25 + 4 = **29** |
| 三號 | 1 | 4 | 1² + 4² = 1 + 16 = **17** |

三個能力值由高到低是 29、17、13，**第二高是 17**，對應到三號角色，所以輸出它的攻擊力與防禦力：`1 4`。

![綜合能力公式與第二高角色的示意](/assets/images/blog/apcs-m931-game-character/goal-second-highest.png){: .normal}
_綜合能力用平方和計算，題目要的是能力值第二高的那名角色。_

## 這題真正的難點在哪裡？

**難點在「找到第二高分之後，還要找回它原本的攻擊力與防禦力」。**

如果你只把每個角色的能力值存起來找第二名，找到的只是一個數字（例如 17），但程式不知道這個 17 原本是哪一名角色。所以能力值與原始資料之間**一定要建立關聯**，才能由「第二高分」追回「原本的攻擊力與防禦力」。

因為保證能力值相異，我們有兩種常見的關聯方式，也就是本篇示範的兩種寫法：

- **方法一**：能力值與原資料分別存在兩個串列，**相同索引**代表同一名角色；找到第二高分後用 `index()` 找出它的位置，再去另一個串列拿原資料。
- **方法二**：把「能力值、攻擊力、防禦力」放進同一個二維串列的一列，排序後直接取倒數第二列。

## 方法一：兩個串列 + 記錄第一、第二高分

這個方法最貼近「手動比大小」的直覺，也是初級最該練熟的寫法。我們準備：

- 一個串列存每個角色原來的「攻擊力 防禦力」字串；
- 一個串列存每個角色的綜合能力值；
- 兩個變數 `number1`、`number2` 隨時記錄「目前的第一高分」與「第二高分」。

每讀進一名角色，就算出能力值，並立刻更新 `number1`、`number2`：

```python
n = int(input())

roles = []    # 倉庫一：存每個角色原來的「攻擊力 防禦力」字串
scores = []   # 倉庫二：存每個角色的綜合能力值

number1 = 0   # 目前第一高的能力值
number2 = 0   # 目前第二高的能力值

for i in range(n):
    a, d = map(int, input().split())
    v = a * a + d * d

    roles.append(f"{a} {d}")
    scores.append(v)

    if v > number1:        # 打破目前第一高分
        number2 = number1  # 原第一高分退居第二
        number1 = v
    elif v > number2:      # 沒破第一，但破了第二高分
        number2 = v

idx = scores.index(number2)   # 第二高分在倉庫裡的位置
print(roles[idx])             # 同一個位置就是那筆原始資料
```

![方法一：用兩個串列分別記錄原始資料與能力值](/assets/images/blog/apcs-m931-game-character/method1-two-lists.png){: .normal}
_方法一：兩個串列用相同索引對應；再用 index() 由第二高分追回原資料。_

### 更新第一與第二高分的關鍵順序

```python
if v > number1:
    number2 = number1
    number1 = v
elif v > number2:
    number2 = v
```

這裡的**順序非常重要**：當 `v` 打破最高分時，要**先**把舊的第一高分交給 `number2`，**再**把 `number1` 換成 `v`。如果寫反了，原本的第二高分就會被蓋掉而消失。若 `v` 沒有超過第一高分，才會進到 `elif` 去比較是不是超過第二高分。

### 用 index() 找回原始資料

```python
idx = scores.index(number2)
print(roles[idx])
```

`scores.index(number2)` 會回傳第二高分在 `scores` 裡的位置，而 `roles` 與 `scores` 是**同一個位置對應同一名角色**，所以 `roles[idx]` 就是那名角色原本的「攻擊力 防禦力」字串，直接印出來即可。

## 方法二：二維串列排序後取倒數第二列

Python 的串列有內建的 `sort()`。如果我們把每一名角色存成一列 `[能力值, 攻擊力, 防禦力]`，**並把能力值放在第一欄**，那麼 `sort()` 就會先依能力值排序，由小排到大，第二高分自然落在**倒數第二列**。

```python
n = int(input())
data = []

for i in range(n):
    a, d = map(int, input().split())
    v = a * a + d * d
    data.append([v, a, d])   # 能力值放最前面

data.sort()                  # 依第一欄（能力值）由小排到大
print(data[-2][1], data[-2][2])   # 倒數第二列就是第二高
```

![方法二：把能力值、攻擊力、防禦力放進二維串列的同一列](/assets/images/blog/apcs-m931-game-character/method2-2d-list.png){: .normal}
_方法二：每一列是 [能力值, 攻擊力, 防禦力]，能力值放第一欄。_

### 為什麼能力值一定要放第一欄？

`sort()` 對二維串列的排序邏輯是**先比第一欄**，第一欄相同時才比第二欄。因為題目保證能力值相異，所以只要把能力值放在第一欄，排序就一定依能力值排好。

### 負索引取倒數第二列

```python
print(data[-2][1], data[-2][2])
```

Python 的負索引很好用：`data[-1]` 是最後一列（能力最高），`data[-2]` 是倒數第二列，也就是**第二高**。那一列是 `[能力值, 攻擊力, 防禦力]`，索引 `1` 是攻擊力、索引 `2` 是防禦力。

![排序後取倒數第二列即為第二高綜合能力](/assets/images/blog/apcs-m931-game-character/sort-2d-list.png){: .normal}
_排序後倒數第二列就是第二高綜合能力的角色，直接取它的攻擊力與防禦力。_

## 兩種方法怎麼選？

| 比較項目 | 方法一：兩個串列 | 方法二：二維串列 + sort |
| --- | --- | --- |
| 核心技巧 | 手動比較大小、`index()` 對應索引 | 二維串列、內建 `sort()`、負索引 |
| 程式長度 | 較長 | 很短 |
| 訓練重點 | 邏輯思考、邊讀邊比 | 熟悉二維串列與現成指令 |
| 適合對象 | 初學者練習程式邏輯 | 已熟悉二維串列的同學 |

兩種都能拿到滿分。建議第一次寫先用**方法一**把邏輯練扎實，等對二維串列有把握後再改用**方法二**，可以寫得更快。

## 範例走讀

以題目第二個範例來驗證方法二（`n = 5`）：

輸入：

```
5
9 2
5 8
1 3
6 6
4 5
```

各角色的綜合能力：

| 角色 | 攻擊力 | 防禦力 | 綜合能力 |
| --- | --- | --- | --- |
| 一號 | 9 | 2 | 81 + 4 = **85** |
| 二號 | 5 | 8 | 25 + 64 = **89** |
| 三號 | 1 | 3 | 1 + 9 = 10 |
| 四號 | 6 | 6 | 36 + 36 = 72 |
| 五號 | 4 | 5 | 16 + 25 = 41 |

能力值由高到低是 89、85、72、41、10，第二高是 **85**，對應到一號角色，輸出 `9 2`。程式把資料排序後取倒數第二列，正好就是 `[85, 9, 2]`，會印出 `9 2`。

## 常見錯誤與除錯

- **輸出成能力值**：題目要的是第二高角色**原本的攻擊力與防禦力**，不是那筆綜合能力數字（常見會誤印 17 或 85）。
- **更新順序寫反**：方法一裡打破第一高分時，要「先」把舊第一交給第二高分，再更新第一高分；順序顛倒會讓第二高分消失。
- **忘記把能力值放第一欄**：方法二若把攻擊力或防禦力放第一欄，`sort()` 就會依錯的欄位排序，答案全錯。
- **`number2` 初始值**：能力值都是正整數，`number1`、`number2` 初始化為 0 即可；若初始化太小或太大都可能出錯。
- **二維串列索引搞混**：`data[-2]` 是一列三個數字，`data[-2][1]` 才是攻擊力、`data[-2][2]` 才是防禦力。

## 常見問題（FAQ）

### 綜合能力是怎麼算的？

**綜合能力 = 攻擊力² + 防禦力²。** 例如攻擊力 5、防禦力 2，綜合能力就是 5×5 + 2×2 = 29。數值越大代表角色越強。

### 為什麼不能只找第二高分的數字就好？

因為題目要輸出的是那名角色**原本的攻擊力與防禦力**，不是能力值數字。所以必須讓「能力值」與「原始資料」建立關聯（同索引，或同放一列），才能由第二高分追回原始資料。

### 保證綜合能力相異有什麼好處？

因為不會同分，所以「第二高」一定唯一，方法是「第一高分歸第一、其餘最大歸第二」就成立，用二維串列排序時也不必煩惱第一欄平手要比第二欄的問題。
